Aviso de privacidad del producto

Este aviso describe las cuentas, el portal y la gestión de dispositivos del producto Browslium cuando esas funciones están habilitadas. Es distinto de la política de privacidad de esta web informativa. Las funciones y los flujos de datos pueden variar según el dispositivo y la etapa de desarrollo.

Política de privacidad de esta web ↗

Responsable y contacto

Browslium LLC, 30 N Gould St, Sheridan, WY 82801, Estados Unidos, es el contacto para este aviso del producto. Envía consultas o solicitudes de privacidad a admin@browslium.com.

Quién puede tener una cuenta

Las cuentas del producto son sólo para adultos. Al registrarse, la persona declara que es adulta; actualmente no se utiliza un servicio de verificación de edad. Acusar recibo de este aviso es distinto de otorgar un consentimiento opcional, que debe solicitarse por separado cuando sea necesario. Un adulto puede administrar un dispositivo usado por otra persona sólo si cuenta con la propiedad, autorización y permisos necesarios. Browslium no ofrece cuentas a menores. Si crees que un menor creó una cuenta, avísanos para que revisemos el caso y tomemos las medidas adecuadas.

Datos de cuenta e identidad

Para crear una cuenta e iniciar sesión, podemos tratar nombre, correo electrónico, identificadores de cuenta, organización o función, eventos de autenticación y datos de sesión. Si eliges iniciar sesión con Google o Microsoft, ese proveedor envía mediante OpenID Connect los datos necesarios para identificar tu cuenta. Su servicio también se rige por sus propias condiciones de privacidad. No nos envíes tu contraseña de Google o Microsoft.

Dispositivos, ajustes y solicitudes

Cuando un adulto inscribe o administra un dispositivo autorizado, el producto puede tratar identificadores y características técnicas del dispositivo, estado de inscripción y conexión, versión de software, políticas asignadas, ajustes por dispositivo, acciones administrativas, solicitudes de excepción y sus resultados. La gestión puede incluir datos de una persona que usa el dispositivo sin ser titular de la cuenta. El titular debe tener la autorización adecuada para configurarlo e informar a las personas afectadas cuando corresponda.

Filtrado y datos técnicos

Filtrar contenido compatible requiere analizarlo para decidir cómo aplicar la política seleccionada. Según el dispositivo, la función y el despliegue, esto puede incluir contenido o señales derivadas, URL o categorías, resultados de decisiones, informes de errores y registros de seguridad. No presupongas que el contenido nunca se transmite o conserva. Actualizaremos este aviso con detalles verificados por función sobre el tratamiento y la conservación antes del acceso general al servicio.

Pagos y mensajes

Si se ofrece el registro de un método de pago, Stripe recibe y almacena los datos de tarjeta mediante su propia interfaz. Browslium puede recibir referencias del cliente y método de pago, estado de configuración o facturación y registros de transacciones necesarios para administrar la cuenta. No te pedimos introducir el número completo de tarjeta en el portal de Browslium. Los mensajes del servicio pueden enviarse mediante Resend; tratamos la dirección de destino, el mensaje y los datos de entrega necesarios. Si contactas a soporte, recibimos la información que decidas enviar.

Para qué usamos los datos

Usamos los datos descritos para ofrecer acceso a la cuenta, inscribir y administrar dispositivos autorizados, aplicar políticas de filtrado elegidas, responder solicitudes de excepción y soporte, comunicarnos sobre el servicio, administrar el registro de pagos y la facturación cuando estén disponibles, proteger el servicio, investigar errores y cumplir obligaciones de registro aplicables. No afirmamos que el producto no trate datos.

Proveedores y ubicaciones

Google y Microsoft pueden prestar el inicio de sesión; Resend, la entrega de correo; Stripe, el registro de pagos o cobros; y DigitalOcean, el alojamiento de infraestructura. Cada uno recibe datos pertinentes a su función. El tratamiento puede ocurrir fuera de tu país, incluso en Estados Unidos. Informaremos otras integraciones o ubicaciones cuando se habiliten; este aviso no afirma que se haya verificado un mecanismo de transferencia internacional para todas las jurisdicciones.

Conservación y seguridad

Los datos necesarios para operar una cuenta o dispositivo administrado, atender solicitudes, proteger el servicio y cumplir obligaciones de registro pueden conservarse durante períodos distintos. Los plazos exactos, el funcionamiento de las copias de seguridad y la conservación por función aún deben verificarse frente al sistema desplegado y se publicarán antes del acceso general. Aplicamos controles de acceso y otras medidas apropiadas al servicio implementado, aunque ningún sistema garantiza seguridad absoluta.

Opciones y solicitudes

Los titulares pueden elegir políticas compatibles y administrar dispositivos y ajustes autorizados donde la función esté disponible. Para solicitar acceso, corrección, eliminación u otra gestión de privacidad, escribe a admin@browslium.com. Puede ser necesario verificar tu identidad y autorización, y conservar ciertos datos cuando la ley aplicable lo exija o permita. Los derechos disponibles dependen de tu ubicación y circunstancias.

Cambios y alcance

Actualizaremos la fecha de publicación y este aviso cuando cambien de forma importante las prácticas de datos del producto. Esta página describe el producto; la política separada de la web cubre las visitas a browslium.com y las aportaciones voluntarias hechas desde el sitio informativo. Publicar este aviso no significa que todas las funciones del producto estén disponibles de forma general.
