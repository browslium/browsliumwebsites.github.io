Política de privacidad

Esta política se aplica al sitio público de Browslium. El servicio de filtrado está en desarrollo y pruebas; esta web no inspecciona el contenido de tu navegación.

Publicada el 6 de octubre de 2026

Lee el aviso de privacidad del producto ↗

Quiénes somos

Browslium LLC opera esta web. Para consultas o solicitudes de privacidad, escribe a admin@browslium.com.

Visitar esta web

Es un sitio estático. No hemos instalado rastreadores publicitarios ni scripts de analítica de terceros. El proveedor de alojamiento puede procesar datos técnicos como dirección IP, navegador, página solicitada y hora para servir y proteger el sitio. Esta web no inspecciona el contenido de otros sitios que visitas.

Preferencia de idioma

La web consulta los idiomas configurados en tu navegador para ofrecer una sugerencia una sola vez. Si eliges un idioma, guardamos esa decisión en el almacenamiento local del navegador para respetarla en visitas posteriores. También se guarda localmente si descartas el aviso. La función de idioma no envía estos ajustes a Browslium. Puedes borrarlos desde la configuración de datos del sitio en tu navegador.

Contacto por correo

El enlace de contacto abre tu aplicación de correo. Si nos escribes, recibimos tu dirección y la información que decidas enviar. Evita contraseñas, números de tarjeta y otros datos sensibles. Usamos el mensaje para responder o investigar tu solicitud y podemos conservar la correspondencia mientras sea necesaria para ese fin o por obligaciones legales. Puedes consultar sobre acceso o eliminación en el mismo correo.

Aportaciones voluntarias

El botón de aportación abre una página de pago alojada por Stripe. Stripe trata los datos de tarjeta bajo sus propias condiciones de privacidad. Esta web no recoge ni almacena esos datos. Browslium puede recibir registros de aportaciones y datos de contacto que Stripe facilite al titular de la cuenta para gestionar las aportaciones, la contabilidad o los registros exigidos. Aportar no compra acceso al producto.

Futuro servicio de filtrado

El producto previsto necesita analizar contenido compatible para tomar decisiones de filtrado. Esta web no activa ese tratamiento. Antes de ofrecer acceso general al servicio, publicaremos información separada y precisa sobre flujos de datos, conservación, seguridad y opciones de usuario basada en el sistema de producción. No afirmamos que el futuro servicio no procese ni almacene nada.

Solicitudes, seguridad y cambios

Puedes escribirnos sobre la información que enviaste por correo o mediante una aportación. Tal vez debamos verificar la solicitud y conservar registros exigidos por ley. Nuestros proveedores de alojamiento, correo o pagos pueden tratar datos en otros países. Ninguna web garantiza seguridad absoluta. Si esta política cambia de forma importante, actualizaremos su fecha y contenido.
